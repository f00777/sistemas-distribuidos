## Escalas de Calificación

- **O: Óptimo** = 3 pts
- **S: Satisfactorio** = 2 pts
- **B: Básico** = 1 pts
- **D: Deficitario** = 0 pts
- **SI** = 1 pts
- **NO** = 0 pts

---

## Criterios de Evaluación

| Dimensión | Indicadores | Criterios de Logro |
| :--- | :--- | :---: |
| **Contenido** | Introduce el caso a abordar, contextualizando, aclarando sus funcionalidades, y motivación de elección del sistema. | O / S / B / D |
| **Contenido** | Se presenta una arquitectura y sus componentes de manera clara, identificando las funcionalidades de cada uno de ellos. | O / S / B / D |
| **Contenido** | Se analiza y discute su arquitectura bajo la mirada de tolerancia a fallos, escalabilidad y disponibilidad histórica del sistema. | O / S / B / D |
| **Contenido** | Se presentan referencias de las fuentes de información utilizadas. | O / S / B / D |
| **Contenido** | La arquitectura y sus componentes poseen la complejidad necesaria para ser abordada por el número de integrantes. | O / S / B / D |
| **Contenido** | Se discute sobre las tecnologías que se implementan y su impacto en las propiedades del sistema. | O / S / B / D |
| **Dominio** | Profundiza en las funcionalidades de los componentes del sistema a analizar. | O / S / B / D |
| **Dominio** | Ejemplifica los conceptos importantes para la comprensión de la audiencia haciendo énfasis en la escalabilidad y disponibilidad. | O / S / B / D |
| **Dominio** | Demuestra dominio en el funcionamiento y propiedades de las tecnologías que se utilizan. | O / S / B / D |
| **Dominio** | Maneja el vocabulario técnico que se requiere para explicar el uso y funcionamiento del sistema. | O / S / B / D |
| **Dominio** | Dan respuesta a las preguntas que se le plantean de manera correcta y argumentada. | O / S / B / D |
| **Exposición** | Utiliza un lenguaje verbal formal y fluido (evita el uso de muletillas, jergas y chilenismos). | O / S / B / D |
| **Exposición** | Utiliza una voz con volumen audible y dicción comprensible que capta la atención del público. | O / S / B / D |
| **Formalidad** | Slides en inglés y cumple con el mínimo de 7 slides. *(Nota: el enunciado especifica mínimo 10 slides)* | SI / NO |
| **Formalidad** | Adecua su exposición al tiempo asignado. | SI / NO |
| **Formalidad** | Envía su presentación al profesor a tiempo. | SI / NO |

| **Material de apoyo** | El material de apoyo aporta a la comprensión del tema, complementando la presentación pero sin sustituir el mensaje oral. | O / S / B / D |
| **Bonus** | Realizan su presentación oral en inglés. | SI / NO |
